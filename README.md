# Centro Cultural Islâmico da Bahia (CCIB)

## Assalamu Aleikum Warahmatullahi Wabarakatuhu!

Bem-vindo(a) ao repositório digital oficial do **Centro Cultural Islâmico da Bahia (CCIB)**.

---

## O que você encontrará aqui

Este repositório é dedicado a hospedar códigos, documentações e recursos digitais que apoiam as operações e projetos do CCIB.


## 💡 Como Contribuir

Se você é um membro da comunidade, desenvolvedor ou designer e deseja apoiar o CCIB, sua ajuda é muito bem-vinda!

1.  **Reporte Bugs:** Encontrou um erro no nosso site ou nos horários de oração? Abra uma [Issue](https://github.com/SEU_USUARIO/SEU_REPOSITORIO/issues).
2.  **Sugira Melhorias:** Tem ideias para novos recursos ou projetos digitais? Abra uma Issue ou entre em contato.
3.  **Desenvolvimento:** Para contribuir com código (ex: no website ou scripts), faça um **Fork** do repositório, implemente as mudanças e envie um **Pull Request (PR)**.
